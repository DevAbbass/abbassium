### ✨ About

**Abbassium** is a client-side Minecraft mod focused on small but useful improvements to the vanilla experience.

The goal is simple: make everyday gameplay more convenient without turning Minecraft into a completely different game.

From inventory management to visual enhancements, Abbassium aims to bring together practical quality-of-life features in one lightweight mod.

Abbassium is built with Fabric and targets **Minecraft Java Edition 26.3**.

### 🚀 Features

The following features are planned for Abbassium:

| **Feature** | **Description** | **Status** |
| --- | --- | --- |
| 🔍 Zoom | Zoom in on the world with a configurable keybind. | Planned |
| 📦 Inventory Sorting | Sort player inventories and supported containers with ease. | Planned |
| 🕒 Chat Timestamps | Display timestamps next to chat messages. | Planned |
| ⚒️ Durability HUD | Keep track of tool and armor durability. | Planned |
| 👆 Container Quick Access | Explore ways to access chests through signs and item frames. | Planned |

> **Note:** Abbassium is currently in development. Features listed above are planned and may not yet be available.

### 🎯 Design Goals

- **Vanilla-friendly:** Preserve the look and feel of Minecraft. 
- **Client-side:** No Abbassium installation required on the server for features that can be implemented entirely on the client. 
- **Lightweight:** Keep the mod focused on useful features without unnecessary overhead. 
- **Configurable:** Provide options and keybinds wherever practical. 
- **Modular:** Build each feature so it can be maintained and improved independently. 
- **Open source:** Make the code accessible to everyone under the Apache License 2.0.

### 📦 Installation

Installation instructions will be added once the first release is available.

In general, you will need:

1. Minecraft Java Edition **26.3**.
2. A compatible installation of the Fabric Loader.
3. Any dependencies specified by the particular Abbassium release.
4. The `abbassium-x.x.x+mcx.x.jar` file, placed in your Minecraft mods directory.

Always make sure that the mod version matches your Minecraft version.
